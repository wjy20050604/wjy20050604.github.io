# Jiayang Wang — Academic Pages

Personal academic website using the original Academic Pages Jekyll template.

Site: https://wjy20050604.github.io

## Editing
- `_config.yml`: site and author settings.
- `_data/navigation.yml`: navigation.
- `_pages/about.md`: English introduction.
- `_pages/publications.md`: publications.
- `_pages/research.md`: research projects.
- `_pages/cv.md`: printable CV.
- `_pages/zh.md`: Chinese introduction.

The repository's existing GitHub Pages build publishes changes from master.
The CV page provides a Print / Save as PDF button. The original uploaded PDF CVs are not included in this repository.

Built with [Academic Pages](https://github.com/academicpages/academicpages.github.io). Original MIT license retained.
